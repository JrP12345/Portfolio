ORBIT

Overview

ORBIT is a comprehensive multi-tenant SaaS platform designed specifically for digital marketing agencies. It provides organization-scoped data isolation, enabling agencies to manage their clients, teams, and projects in a secure and scalable environment.

Key Features

Asymmetric JWT Authentication

Implemented RS256-based authentication supporting dual-entity access for agency owners and invited team members.

Dynamic RBAC System

Built a permission-based Role-Based Access Control system enabling organization-level role management with granular permissions.

Task Lifecycle Workflow

Engineered a complete task lifecycle workflow system: request → execution → approval → publishing.

Enterprise Security

Strengthened backend security using Helmet, rate limiting, httpOnly cookies, and secure password hashing with Bcrypt.
